# Авторская графика

Обложки `cover-mera.svg`, `cover-quiet-form.svg`, `cover-polyus.svg`, фирменная графика `og-cover.svg` и `favicon.svg` созданы специально для концептуального проекта SOUNDWAVE Studio. Использованы оригинальные векторные композиции, без сторонних изображений.

Все названия артистов, релизов и кейсы вымышлены. Совпадения случайны. Обложки не сопровождаются аудиозаписями.

Эти графические файлы доступны по [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
