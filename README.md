# SOUNDWAVE Studio

Авторский одностраничный сайт вымышленной студии звукозаписи. Портфолийный проект с редакционной композицией, крупной типографикой, атмосферными фотографиями и оригинальными обложками музыкальных кейсов.

[Сайт на GitHub Pages](https://retrobanan.github.io/soundwave-studio/) · [Репозиторий](https://github.com/ReTrOBANAN/soundwave-studio)

Студия, артисты, проекты и тарифы вымышлены. Фотографии иллюстрируют визуальную концепцию и не изображают помещение реальной SOUNDWAVE Studio. Здесь нет отзывов, фиктивных клиентов, аудиозаписей или настоящего бронирования.

## Стек и возможности

- HTML5, CSS3, Vanilla JavaScript ES6+. Без сборки, библиотек интерфейса, серверной части и платных API.
- Адаптивная композиция от 360 px, локальный вариативный Manrope с кириллицей, локальные WebP и SVG.
- Плавная навигация, активные ссылки, мобильное меню с удержанием фокуса, закрытием по Escape и блокировкой прокрутки.
- FAQ с анимацией, ARIA-состояниями и управлением клавишами Enter, Space, стрелками, Home и End.
- Диалоги визуальных кейсов и фотогалерея. В галерее работают стрелки клавиатуры, в диалогах — Escape и возврат фокуса.
- Валидация демонстрационной формы: имя, email, услуга и описание проекта. Ошибки привязаны к полям, фокус переходит к первой ошибке.
- Появление секций через Intersection Observer, поддержка `prefers-reduced-motion`, видимый клавиатурный фокус и ссылка пропуска навигации.
- Title, description, Open Graph, локальная картинка для превью и SVG favicon.

## Запуск

Из корня проекта:

```sh
python3 -m http.server 4173
```

Откройте [localhost:4173](http://localhost:4173). Остановить сервер — `Ctrl+C`.

Установка зависимостей не нужна. Также можно открыть `index.html` напрямую, но локальный HTTP-сервер удобнее для проверки загрузки ресурсов и ближе к условиям публикации.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки в его корень, сохранив структуру каталогов.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку **/ (root)**.
4. Сохраните настройки и дождитесь публикации. GitHub покажет итоговый адрес сайта.

Все пути относительные: сайт подходит и для адреса `username.github.io`, и для `username.github.io/repository/`. Файл `.nojekyll` отключает ненужную обработку Jekyll. Секретов и переменных окружения нет.

Настройка источника публикации описана в [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

В `index.html` настроены `og:url`, canonical и абсолютный адрес `og:image` для `https://retrobanan.github.io/soundwave-studio/`. При переименовании репозитория или смене владельца обновите эти адреса и ссылки в README.

## Форма и подключение API

Форма **не отправляет и не сохраняет данные**: нет `fetch`, почтовых ссылок, аналитики, cookies, `localStorage` или сторонних обработчиков. После успешной проверки прямо сообщается, что заявка не отправлена. Поля остаются заполненными только в текущей странице; их значения не записываются кодом сайта в постоянное хранилище. Браузер может отдельно предлагать собственное автозаполнение.

Для подключения настоящей отправки измените обработчик `submit` в `js/script.js`: после успешной валидации сформируйте данные из `#contact-form` и передайте в свой API. Показывайте подтверждение отправки только после успешного ответа. Секретные ключи должны оставаться на сервере; GitHub Pages исполняет только клиентский код.

Источники, авторы фотографий и лицензия шрифта перечислены в [assets/SOURCES.md](assets/SOURCES.md). Авторские обложки, знак и OG-графика описаны в [assets/COVERS.md](assets/COVERS.md). Все необходимые ресурсы находятся в репозитории; при посещении сайт не обращается к фотобанкам или Google Fonts.

## Проверка

Информация о фактически выполненных проверках находится в [QA.md](QA.md). Для самостоятельной проверки после изменения содержимого:

- Проверьте размеры 360, 390, 430, 768, 1024, 1440 и 1920 px: отсутствие горизонтальной прокрутки, читаемость, полную видимость заголовков.
- Откройте мобильное меню, пройдите ссылки клавишей Tab, закройте по Escape и выберите раздел.
- Откройте FAQ, кейс и фотографию; проверьте фокус и клавиатурную навигацию.
- Отправьте пустую форму, ошибочный email и корректные данные; реальных запросов отправки быть не должно.
- Проверьте консоль и вкладку Network. Lighthouse следует запускать через HTTP, без расширений и с зафиксированными условиями измерения.

Численные оценки Lighthouse не заявляются без отдельного измерения.
