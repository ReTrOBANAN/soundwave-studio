# Проверка SOUNDWAVE Studio

Дата: **31 октября 2026 года**. Проверка через локальный HTTP-сервер, существующий Google Chrome **156.0.8078.76** в headless-режиме и Playwright Core. Инструменты проверки установлены во временный каталог и не являются зависимостями сайта.

В ходе нескольких прогонов подтверждены **13 сценариев поведения**. В дополнительном прогоне тест меню проверил фокус раньше запланированного `requestAnimationFrame`, что вызвало ошибку ожидания в тестовом сценарии. Ранее тот же код меню прошёл проверки фокуса, Escape и перехода по ссылке; после этого код меню не менялся. Дополнительно выполнена проверка синтаксиса `node --check js/script.js`, статическая проверка ресурсов и визуальная проверка снимков на 390 и 1440 px.

## Границы проверки

Проверка выполнена в одном браузерном движке, без реальных мобильных устройств и скринридера. Lighthouse не запускался; оценки Performance, Accessibility и Best Practices не заявляются. Публикация на GitHub Pages не выполнялась: проект подготовлен к публикации из корня, инструкция находится в README. Настоящая отправка формы и воспроизведение аудио намеренно не реализованы в демонстрационном проекте.

## После визуальных правок

Обновлены заголовок и метаданные, кнопка шапки, SVG-стрелки, подписи этапов и высота поля сообщения; удалены указанные пользователем подписи. Выполнена статическая проверка удалений, локальных ресурсов, ID, якорей, ARIA-ссылок, структуры CSS и синтаксиса JavaScript. Изображение Open Graph перегенерировано из обновлённого SVG. Повторная браузерная проверка этих изменений не выполнялась: запуск Chrome был отменён пользователем. Результаты браузерных проверок выше относятся к первоначальной версии.
